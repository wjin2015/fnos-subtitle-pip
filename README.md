# FNOS Subtitle PiP 0.5.1

飞牛影音（FNOS）网页播放器的 Edge 扩展：把视频和实时字幕一起放进画中画窗口，
画中画期间原页面不再显示画面，并支持在画中画内直接做播放控制、选集与连播。

## 功能

- **双模式画中画，自动选择**
  - **文档画中画**（`documentPictureInPicture`）：页面为 HTTPS / localhost 等安全上下文时使用。
    字幕是画中画窗口内的 DOM 层，播放/暂停、进度、静音、音量控件都在画中画窗口里。
  - **视频画中画**（canvas 字幕合成 + `video.requestPictureInPicture()`）：
    HTTP 页面（如 `http://192.168.x.x` 访问 NAS）同样可用。
    字幕按源页面样式（颜色/字号/字重/阴影/底色）实时绘制进视频帧，
    页面右上角提供控制面板，声音保留在原页面播放器输出。
    文档画中画不可用或调用失败时自动降级到此模式。
- **两种触发方式**：点击扩展工具栏图标，或按 `Alt+P`（可在 `edge://extensions/shortcuts` 改）。
  画中画已开启时再次触发即关闭。页面内不再注入任何按钮，其他页面完全无感知。
- **画中画内调整字幕大小**：`A−` / `A+` 调节，范围 50%–250%，倍率持久化到 `chrome.storage.local`。
  - 文档画中画：画中画窗口工具条上的 `A−` / `A+`。
  - 视频画中画：页面控制面板上的 `A−` / `A+`。
- **播放控制（两种模式均有）**
  - `播放` / `暂停`：直接控制原播放器。暂停后再次点击即可恢复，播放状态在
    「画中画窗口自带按钮 ↔ 页面控制面板 ↔ MediaSession」之间双向同步，不会出现按钮失灵或画面冻住。
  - `−10s` / `+10s` 快退快进：**单击**跳 10 秒；**按住不放**以 1 秒/100ms 连续跳转，松开即停。
  - 文档画中画还带进度条（`seek` 滑块）与音量控制。
  - 画中画窗口自带的播放/暂停按钮、系统媒体控制中心（OSD / 耳机线控）同样生效
    （通过 MediaSession 的 `play` / `pause` / `seekbackward` / `seekforward` 映射）。
- **剧集切换（识别到连播列表时自动出现）**
  - `上一集` / `下一集`：调用页面自身的剧集项点击逻辑，不改写播放器状态。
  - `选集`：弹出剧集浮层，列出全部集数并高亮当前集，点击即切换，切换后浮层自动关闭。
  - 切集后自动重绑视频源：模式 A 重新 `captureStream()`，模式 B 重新启动 Canvas 合成，画中画不断流。
  - 剧集识别为启发式：优先匹配 `[class*=episode]` 等常见剧集容器，兜底扫描文本形如
    「1 / 12 / 第3集 / 第3话 / END / 预告 / 片头 / 彩蛋」等可见项，取数量最多的一组。
    若当前播放器未使用剧集容器，则按钮不出现或提示「未识别到剧集列表」。
- **连播时画中画自动跟随**：识别到剧集列表后，视频播完画中画会继续播下一集，
  不需要退出画中画回页面重新开启。分两种情形：
  - 页面自身支持连播：扩展不插手，页面换源/重建播放器后画中画自动重绑，画面与字幕无缝接续；
  - 页面不连播：播完约 1.2 秒后由扩展自动点「下一集」继续播，并提示「连播：已切换到下一集」。
  - 已是最后一集时提示「已是最后一集」，不会反复触发。
  - 换集后会同步：原页面视频继续保持隐藏、画布分辨率跟随实际视频、选集浮层高亮刷新。
- **画中画期间隐藏原页面画面**（`opacity:0`，视频仍在解码出声），退出后自动恢复默认显示。
- 通过 MutationObserver + 定时刷新跟踪字幕 DOM 变化（播放器重渲染后自动重新挂载）。

## 安装（Microsoft Edge）

1. 下载并解压 `fnos-subtitle-pip.zip`。
2. Edge 地址栏打开 `edge://extensions/`。
3. 打开「开发人员模式」。
4. 点击「加载解压缩的扩展」，选择解压后的 `fnos-subtitle-pip` 文件夹。
   （升级旧版时请先删除旧扩展再重新加载，避免改动未生效。）
5. 打开飞牛影音网页，进入视频播放页面并开启字幕。
6. 按 `Alt+P` 或点击扩展图标开启画中画。

## 排查

### 「当前 Edge 不支持 Document Picture-in-Picture」（0.2.0 已修复）
旧版本在 HTTP 页面会误报此错误并要求更新 Edge。实际原因是 Document Picture-in-Picture
API 有安全上下文（`[SecureContext]`）限制，仅在 HTTPS / localhost 下暴露；
`http://192.168.x.x` 访问时该 API 完全不存在（与 Edge 版本无关，Edge 116+ 均支持，
已在 Edge 155 实测验证）。0.2.0 起 HTTP 页面自动改用「视频画中画 + Canvas 字幕合成」。

### 画中画窗口持焦时按 Alt+P 无反应（0.3.1 已修复）
这不是快捷键失效：`chrome.commands` 仍会正常派发。根因是画中画窗口是独立的浏览器窗口，
`tabs.query({active:true, currentWindow:true})` 此时返回的是画中画自己的 `about:blank`
标签页，消息投递不到原视频页。0.3.1 起由 background 记住承载画中画的标签页 id 并直接投递。

### 快进 / 快退无效
- 先确认原播放器能正常拖动进度条（扩展是直接设置 `video.currentTime`，播放器侧限制会同样生效）。
- 直播 / 时移内容（`duration` 为 `Infinity` 或不可 seek）无法快进快退，会提示「无法快进/快退」。
- 片源未做 faststart（moov 在文件尾部）时，拖动可能长时间无响应，属片源问题。

### 没有「上一集 / 下一集 / 选集」按钮
说明当前页面未识别到剧集列表。可尝试：进入播放页的剧集 Tab 让列表渲染出来后再开画中画。
识别规则见上文「剧集切换」。

### 连播时画中画不动 / 要回页面重开
- 确认当前页面确实有关联的剧集列表（有「上一集/下一集/选集」按钮才可能连播）。
- 播放器在后台标签页里被浏览器限流时，扩展用定时器兜底检测换集；若播放器自身
  在页面不可见时停止解码，画中画会停在最后一帧，这是播放器策略，扩展无法绕过。
- 播完 1.2 秒内页面自己接上了连播，扩展就不会重复切集（避免一次播两集）。

### 暂停后点「播放」没反应 / 画面冻住（0.5.1 已修复）
- 若画中画窗口自带的播放按钮点了没动静：确认是否曾用页面控制面板暂停过。
  视频画中画模式下画中画元素只是 canvas 流的载体，早期版本没有把它的播放态与源视频同步，
  导致它停留在播放态时再次 `play()` 不会派发 `play` 事件，恢复逻辑根本不执行。
- 若声音在放但画面不动：同上，画中画元素停在暂停态所致。0.5.1 起播放状态双向同步。
- 若提示「无法播放：NotAllowedError」：浏览器自动播放策略拦截了未激活文档的播放，
  回页面点击一次播放器获得激活后再试。

### 其他常见问题
- 提示找不到视频：确认视频正在播放，并且视频元素可见。
- 提示找不到字幕容器：确认当前页面 DOM 仍使用 `trim-ui__player-subtitle-mount-point-wrapper`。
- PiP 黑屏/冻结：确认片源非 DRM；视频画中画模式下可查看页面控制面板的「字幕：」预览确认字幕检测是否正常。
- 字幕为空：确认原页面字幕已开启；再检查字幕容器内部是否存在可见文本叶子节点。
- 出错时会弹出环境诊断（页面协议、安全上下文、Document PiP / captureStream / 视频 PiP 可用性），反馈时请一并提供。
- 页面 `<html>` 上的 `data-fnos-pip-mode` 属性（`document` / `canvas`）可标识当前使用的模式。

## 已知限制

- 视频画中画模式为经典视频 PiP：进度条无法放进画中画窗口（浏览器限制），
  播放/暂停、快进快退、选集通过页面控制面板操作；画中画窗口自带的播放/暂停会同步原播放器。
- 两种模式均将声音保留在原页面播放器输出，画中画视频本身静音，避免双重音频。
- 受 DRM / 受保护内容影响时无法捕获画面，画中画可能黑屏；请使用非加密片源测试。
- 若播放器在页面切到后台时自动暂停（播放器自身策略），画中画会停在最后一帧。
  后台标签页实测（Edge 155）：播放声音时画中画保持约 30fps，字幕照常更新。
- 字幕提取会优先选取字幕挂载容器内可见的叶子文本节点。若容器同时包含提示文本或多个字幕层，
  可能需要根据实际 DOM 微调选择器。
- 画中画字幕样式目前做近似同步，定位在画中画窗口底部区域，不保证与原页面位置完全一致。
- 选集依赖页面自身 DOM 结构，播放器改版后可能需要调整剧集容器选择器。
- 连播的「扩展兜底切集」以页面剧集列表的当前高亮项为准，若播放器用非 class 方式标记当前集
  导致判不出当前位置，扩展不会自动切集（宁可不动作），此时仍可用画中画里的「下一集」按钮。

## 文件

- `manifest.json`：扩展清单
- `background.js`：服务工作线程，负责把图标点击 / `Alt+P` 路由到正确的标签页
- `content.js`：扩展主体
- `test/`：回归测试脚手架（Edge + CDP 驱动，非扩展运行所需，可整个删除）
  - `range-server.cjs`：带 HTTP Range 支持的静态服务器。**必须先启动**——
    Python `http.server` 不支持 Range，mp4 会整体无法 seek，快进快退类功能会全部误判为失败。
  - `drive-ext.cjs`：E2E 驱动，24–27 项检查（模式 B 比模式 A 多 3 项画中画播放态同步检查）。用法：
    `node drive-ext.cjs <url> <canvas|document> [src|rebuild]`
    （`rebuild` 模拟播放器销毁并重建 video 元素的严苛场景）
  - `play-probe.cjs`：专项探针，用**真实 CDP 鼠标点击**和**带声音的视频**复现真实场景，
    覆盖面板播放按钮、画中画窗口自带播放按钮、以及「画面冻住」反向症状。
    用法：`node play-probe.cjs <url> <canvas|document>`
    （`el.click()` 不带用户激活、muted 样本会完全绕过浏览器自动播放策略，测不出这类问题）
  - `seek-probe.cjs`：不带扩展，单独验证样本视频可 seek
  - `www/`：模拟飞牛播放页与样本视频
